# 测试工程师岗位要求

## 岗位概述
负责产品质量保障工作，制定并执行测试策略，设计测试用例，执行功能、性能、自动化等多维度测试，确保产品高质量交付。

## 硬性要求
- 学历：本科及以上学历，计算机科学、软件工程等相关专业
- 经验：2年以上软件测试工作经验
- 基础：熟悉软件测试理论，掌握常用测试方法和工具

## 核心技能要求

### 1. 测试基础能力（权重：高）
- 精通黑盒测试方法（等价类、边界值、正交法、场景法）
- 能编写高质量的测试用例和测试报告
- 熟悉测试流程管理（需求评审→用例设计→执行→缺陷跟踪→回归）
- 具备探索性测试能力
- 了解白盒测试方法优先

### 2. 自动化测试能力（权重：高）
- 熟练使用至少一种自动化测试框架（Selenium/Cypress/Playwright）
- 具备 API 自动化测试能力（Postman/RestAssured/pytest）
- 能搭建和维护自动化测试框架
- 熟悉 Page Object 等设计模式在测试中的应用
- 掌握至少一种编程语言（Python/Java/JavaScript）

### 3. 接口测试能力（权重：中）
- 熟练进行 RESTful API 测试
- 了解 HTTP 协议、常见状态码和请求方法
- 能使用 Charles/Fiddler 等抓包工具
- 了解 gRPC、WebSocket 等协议测试

### 4. 性能测试能力（权重：中）
- 熟悉性能测试工具（JMeter/Locust/K6）
- 能设计性能测试方案（压力测试、负载测试、稳定性测试）
- 具备性能瓶颈分析和定位能力
- 了解性能指标（QPS、TPS、响应时间、吞吐量）

### 5. 数据库与Linux（权重：低）
- 熟悉 SQL 查询，能进行数据验证
- 了解 Linux 基本操作和日志查看
- 熟悉 Redis 等缓存的基本操作

### 6. 测试管理与协作（权重：低）
- 熟悉缺陷管理工具（Jira/禅道/Bugzilla）
- 熟悉测试管理工具（TestRail/TestLink）
- 具备良好的沟通和文档能力
- 了解 CI/CD 中的测试集成

## 评分标准

| 维度 | 分值 | 评分依据 |
|------|------|---------|
| 学历背景 | 15分 | 学历层次、院校水平、专业相关性 |
| 工作经验 | 20分 | 测试年限、测试类型广度、行业经验 |
| 技能匹配 | 25分 | 测试技能与岗位要求的匹配度 |
| 项目经验 | 20分 | 项目规模、测试体系建设、质量成果 |
| 稳定性 | 10分 | 工作连续性、跳槽频率 |
| 发展潜力 | 10分 | 技术学习能力、测试思维、专业成长 |

## 加分项
- 有大型项目质量保障体系搭建经验
- 具备 DevOps/持续测试实践经验
- 了解安全测试基础（SQL注入、XSS等）
- 有移动端 APP 测试经验（iOS/Android）
- 持有 ISTQB 等测试相关认证
- 有测试团队管理经验

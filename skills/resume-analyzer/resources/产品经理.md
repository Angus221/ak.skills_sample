# 产品经理岗位要求

## 岗位概述
负责产品全生命周期管理，从需求调研、产品规划、设计到上线运营，推动产品持续迭代优化。

## 硬性要求
- 学历：本科及以上学历，计算机、软件工程、市场营销、工商管理等相关专业优先
- 经验：3年以上互联网产品经理工作经验
- 工具：熟练使用 Axure、Figma、Sketch 等原型设计工具，熟练使用 Visio/ProcessOn 等流程图工具

## 核心技能要求

### 1. 需求分析能力（权重：高）
- 能够独立进行用户调研（访谈、问卷、数据分析）
- 善于从用户反馈中提炼核心需求
- 具备竞品分析能力，能输出结构化的分析报告
- 熟悉需求优先级评估方法（如 KANO 模型、ICE 评分）

### 2. 产品规划能力（权重：高）
- 能制定产品路线图（Roadmap）
- 具备商业模式分析能力
- 了解用户增长策略和生命周期管理
- 有数据驱动决策的思维和实践经验

### 3. 项目推动能力（权重：中）
- 能有效协调开发、设计、测试等多个团队
- 具备良好的项目管理能力，能推动项目按时交付
- 有敏捷开发（Scrum/Kanban）实践经验

### 4. 文档与沟通能力（权重：中）
- 能输出高质量的 PRD（产品需求文档）
- 具备清晰的逻辑表达能力
- 优秀的跨部门沟通协调能力

### 5. 数据分析能力（权重：中）
- 熟悉常用数据分析工具（如 SQL、Excel、BI 工具）
- 能建立产品数据指标体系
- 具备 A/B 测试设计和分析能力

### 6. 行业知识（权重：低）
- 了解所在行业的市场趋势
- 关注前沿技术（如 AI、大数据）对产品的影响

## 评分标准

| 维度 | 分值 | 评分依据 |
|------|------|---------|
| 学历背景 | 15分 | 学历层次、院校水平、专业相关性 |
| 工作经验 | 20分 | 产品经理年限、行业经验、管理经验 |
| 技能匹配 | 25分 | 核心技能与岗位要求的匹配度 |
| 项目经验 | 20分 | 产品项目的规模、成果和创新性 |
| 稳定性 | 10分 | 工作连续性、跳槽频率 |
| 发展潜力 | 10分 | 学习能力、成长轨迹、综合素质 |

## 加分项
- 有从0到1的产品搭建经验
- 有千万级用户产品管理经验
- 有 B端/C端/平台型产品的跨领域经验
- 有创业经历
- 持有 PMP、NPDP 等产品相关认证

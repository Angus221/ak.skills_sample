# Java工程师岗位要求

## 岗位概述
负责公司后端服务的设计与开发，构建高性能、高可用、可扩展的分布式系统，保障业务稳定运行。

## 硬性要求
- 学历：本科及以上学历，计算机科学、软件工程等相关专业
- 经验：3年以上 Java 后端开发工作经验
- 基础：扎实的 Java 语言基础和面向对象设计能力

## 核心技能要求

### 1. Java 核心能力（权重：高）
- 精通 Java SE，深入理解 JVM 内存模型、GC 机制、类加载原理
- 熟练掌握多线程与并发编程（线程池、锁机制、CAS、AQS）
- 深入理解集合框架源码（HashMap、ConcurrentHashMap 等）
- 熟悉 JDK 8+ 新特性（Stream、Lambda、Optional）
- 了解 JVM 调优与故障排查（jstack、jmap、arthas）

### 2. Spring 生态（权重：高）
- 精通 Spring Boot、Spring MVC
- 深入理解 Spring IoC、AOP 原理
- 熟练使用 Spring Cloud 微服务全家桶（Gateway、Feign、Nacos、Sentinel）
- 了解 Spring Security / OAuth2 安全框架
- 有 Spring Cloud Alibaba 经验优先

### 3. 数据库与缓存（权重：高）
- 精通 MySQL，理解索引原理、事务隔离、SQL 调优
- 熟练使用 Redis，了解数据结构、持久化、集群方案
- 熟悉 MyBatis/MyBatis-Plus ORM 框架
- 了解分库分表方案（ShardingSphere）
- 了解 NoSQL 数据库（MongoDB、Elasticsearch）

### 4. 分布式与微服务（权重：中）
- 理解分布式系统设计原则（CAP、BASE）
- 熟悉消息队列（Kafka/RocketMQ/RabbitMQ）
- 了解分布式事务解决方案（Seata、TCC、Saga）
- 有服务治理经验（限流、熔断、降级、链路追踪）
- 了解容器化技术（Docker、Kubernetes）

### 5. 系统设计能力（权重：中）
- 具备系统架构设计能力
- 熟悉常用设计模式并能合理应用
- 能进行技术方案评审和选型
- 有高并发/高可用系统设计经验优先

### 6. 工程实践（权重：低）
- 熟练使用 Git 进行版本控制
- 熟悉 Maven/Gradle 构建工具
- 了解 CI/CD 流程（Jenkins/GitLab CI）
- 有单元测试编写习惯（JUnit、Mockito）

## 评分标准

| 维度 | 分值 | 评分依据 |
|------|------|---------|
| 学历背景 | 15分 | 学历层次、院校水平、专业相关性 |
| 工作经验 | 20分 | Java开发年限、技术深度、团队角色 |
| 技能匹配 | 25分 | 核心技术栈与岗位要求的匹配度 |
| 项目经验 | 20分 | 项目复杂度、系统规模、技术挑战 |
| 稳定性 | 10分 | 工作连续性、跳槽频率 |
| 发展潜力 | 10分 | 技术深度、架构能力、学习成长 |

## 加分项
- 有大型分布式系统开发经验（日活百万级以上）
- 有开源框架源码研读或贡献经验
- 有技术团队管理或技术指导经验
- 持有 OCP（Oracle Certified Professional）等认证
- 有性能调优实战经验（JVM、SQL、系统级别）
- 有 DDD（领域驱动设计）实践经验

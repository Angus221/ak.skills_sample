# 项目经理岗位要求

## 岗位概述
负责项目全生命周期管理，从项目启动、规划、执行、监控到收尾，确保项目在预定的时间、成本和质量范围内成功交付。

## 硬性要求
- 学历：本科及以上学历，计算机科学、软件工程、信息管理、工商管理等相关专业
- 经验：5年以上IT行业工作经验，其中3年以上项目管理经验
- 认证：PMP 认证优先，ACP/CSM 等敏捷认证优先

## 核心技能要求

### 1. 项目管理能力（权重：高）
- 精通项目管理五大过程组（启动、规划、执行、监控、收尾）
- 熟练运用项目管理十大知识领域
- 具备项目范围管理能力（WBS 分解、变更控制）
- 擅长项目进度管理（甘特图、关键路径法、资源平衡）
- 有效的风险管理能力（识别、评估、应对、监控）

### 2. 敏捷管理能力（权重：高）
- 熟练运用 Scrum/Kanban 等敏捷方法论
- 能主持各类敏捷会议（站会、评审、回顾、规划）
- 具备 Sprint 规划和管理能力
- 了解规模化敏捷框架（SAFe/LeSS）
- 能灵活运用混合管理方法（瀑布+敏捷）

### 3. 团队管理能力（权重：高）
- 具备团队组建和梯队建设能力
- 擅长跨职能团队协调（开发、测试、设计、产品）
- 有效进行冲突管理和问题解决
- 能激励团队成员，提升团队士气和效能
- 有远程/分布式团队管理经验优先

### 4. 沟通与干系人管理（权重：中）
- 优秀的向上汇报能力（周报/月报/里程碑汇报）
- 能有效管理客户期望和需求
- 具备跨部门沟通协调能力
- 擅长组织和引导各类会议

### 5. 技术理解力（权重：中）
- 了解软件开发生命周期（SDLC）
- 能理解技术架构和技术方案
- 具备基本的技术风险评估能力
- 了解 DevOps 和 CI/CD 流程

### 6. 工具运用（权重：低）
- 熟练使用项目管理工具（Jira/禅道/MS Project/Tapd）
- 熟悉文档协作工具（Confluence/飞书/钉钉）
- 会使用数据分析工具进行项目数据分析
- 了解项目管理信息系统（PMIS）

## 评分标准

| 维度 | 分值 | 评分依据 |
|------|------|---------|
| 学历背景 | 15分 | 学历层次、院校水平、专业相关性、证书认证 |
| 工作经验 | 20分 | 项目管理年限、管理项目规模、行业经验 |
| 技能匹配 | 25分 | 管理能力与岗位要求的匹配度 |
| 项目经验 | 20分 | 项目规模、复杂度、交付成果 |
| 稳定性 | 10分 | 工作连续性、跳槽频率 |
| 发展潜力 | 10分 | 管理视野、学习能力、领导力 |

## 加分项
- 有百人以上团队的项目管理经验
- 有千万级以上预算的项目管理经验
- 有跨国/跨区域项目管理经验
- 有多个项目同时管理（PMO）经验
- 有从传统管理到敏捷转型的实践经验
- 有甲方和乙方双重项目管理视角

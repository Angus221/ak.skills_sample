# 前端开发岗位要求

## 岗位概述
负责公司Web前端应用的开发与维护，构建高性能、高可用的用户界面，提供卓越的用户体验。

## 硬性要求
- 学历：本科及以上学历，计算机科学、软件工程等相关专业
- 经验：3年以上前端开发工作经验
- 基础：扎实的 HTML、CSS、JavaScript/TypeScript 基础

## 核心技能要求

### 1. 前端框架能力（权重：高）
- 精通 React/Vue/Angular 中至少一个主流框架
- 深入理解框架原理（虚拟DOM、响应式、组件生命周期）
- 熟悉状态管理方案（Redux/Vuex/Pinia/Zustand）
- 有 SSR/SSG 经验（Next.js/Nuxt.js）优先

### 2. JavaScript/TypeScript 深度（权重：高）
- 深入理解 ES6+ 特性（Promise、async/await、解构、模块化）
- 熟练使用 TypeScript，具备类型体操能力
- 理解事件循环、闭包、原型链等核心概念
- 了解 V8 引擎优化原理优先

### 3. CSS 与布局能力（权重：中）
- 精通 Flexbox、Grid 布局
- 熟悉 CSS 预处理器（Sass/Less）或 CSS-in-JS 方案
- 熟练使用 TailwindCSS 等原子化 CSS 框架
- 具备响应式设计和移动端适配能力
- 了解 CSS 动画和过渡效果

### 4. 工程化能力（权重：中）
- 熟悉 Webpack/Vite/Rollup 等构建工具
- 具备前端性能优化经验（包体积、加载速度、渲染性能）
- 熟悉 CI/CD 流程
- 了解微前端架构（如 qiankun、Module Federation）

### 5. 跨端开发能力（权重：低）
- 有 React Native / Flutter / Electron 等跨端开发经验
- 熟悉小程序开发（微信/支付宝）
- 了解 PWA 技术

### 6. 协作与工具（权重：低）
- 熟练使用 Git 进行版本控制
- 熟悉前端测试（Jest、Cypress、Playwright）
- 了解 RESTful API 和 GraphQL
- 具备良好的代码规范意识（ESLint、Prettier）

## 评分标准

| 维度 | 分值 | 评分依据 |
|------|------|---------|
| 学历背景 | 15分 | 学历层次、院校水平、专业相关性 |
| 工作经验 | 20分 | 前端开发年限、技术深度、团队角色 |
| 技能匹配 | 25分 | 核心技术栈与岗位要求的匹配度 |
| 项目经验 | 20分 | 项目复杂度、技术挑战、业务成果 |
| 稳定性 | 10分 | 工作连续性、跳槽频率 |
| 发展潜力 | 10分 | 技术视野、学习能力、开源贡献 |

## 加分项
- 有大型复杂单页应用（SPA）开发经验
- 有组件库/工具库的开发和维护经验
- 有技术博客或开源项目贡献
- 有前端架构设计经验
- 了解 WebGL/Three.js/Canvas 等可视化技术
- 了解 WebAssembly 技术
